01｜本次方案的四项决定

投资边界

仅使用合法可支配的自有资金投资A、美、港股及ETF；先以主观多头为主、低频因子为辅助；中期以训练AI为主、后期以人辅助AI。

AI工作方式

初期由研究员主导，AI负责资料提取、研究初稿与因子试验；中期沉淀研究样本和人工反馈，持续训练、评测投研Agent；后期形成AI主导、人辅助的研究与组合建议流程，由团队设定目标、监督风险并处理例外。

组织口径

Q4团队五人，岗位平行：行研2、因子研究2、AI架构师1。

资本节奏

先以1,000万元试运行，符合条件后申请至2,000万元；初期累计上限5,000万元。

02｜资金爬坡与加资依据

额度以人民币计；首期以A股为主，按分市场及合并净值复核

Q4试运行1,000万

首期以A股为主；账户、研究、交易和日对账流程跑通，形成连续实盘净值。

第一档加资≤2,000万

至少连续运行4周；参考累计净收益≥4%、最大回撤≤3%，团队与流程稳定。

第二档加资≤3,500万

在2,000万档至少再运行1个月；参考累计净收益≥7%、最大回撤≤5%。

初期资金封顶≤5,000万

在3,500万档至少再运行1个月，且完整实盘满3个月；参考累计净收益≥9%、最大回撤≤7%。

长期扩大1亿→2亿元

分别独立评估；业绩、容量、团队及跨市场运营能力匹配后申请。

加资依据统一核查口径未达标时
盈利质量4%／7%／9%的阶段参考线，按扣除交易成本、剔除出入金影响的同一实盘净值序列计算；同时看相对基准表现和收益来源，不能靠单一事件或临时放大仓位冲目标。留在原资金档继续运行、复盘收益来源。
跨市场口径A股、美股、港股及ETF分别记账，合并净值按统一汇率来源与估值时点折算成人民币；分别展示分市场收益、回撤及汇率贡献。首期资金主要投向A股，其他市场按账户与数据准备情况逐步纳入。折算和对账口径未统一前，不以合并业绩申请加资。
回撤约束对应档位观察最大回撤3%／5%／7%；单日回撤达到3%即检查持仓、交易与数据。突破阶段回撤线，暂停加资并查明原因。先处理风险和异常；继续观察并保留完整历史净值。
运行与团队首档至少运行4周，此后每档至少运行1个月；订单、成交、持仓与现金每日核对。核心岗位能覆盖研究、因子验证、AI系统和交易运营，未结重大异常为零。补齐岗位或流程，当前额度维持不变。
加资节奏相邻档位分次投入，单次新增资金原则上不超过原档额度的80%；1,000万至2,000万可分为1,500万、2,000万两次执行，避免一次性扩大仓位。保持原档，待交易和风控适应后再投入。
资金容量加资后重新测算持仓集中度、流动性、交易冲击、跨市场汇率与结算安排；资金从3,500万至5,000万时重点检查策略容量。缩小加资幅度或调整投资范围。

03｜五人分工

五个平行岗位：2行研＋2因子＋1 AI架构师

岗位主要职责Q4交付协作与交叉复核
行研A｜现有覆盖行业组A；形成公司与ETF投资假设、估值情景及反方观点；跟踪相关持仓。5–7家公司档案、2–3份完整投资备忘录；每周更新持仓事件与研究结论。行研B核对关键事实；因子研究员验证可量化信号。参与复核他人提案。
行研B｜新增覆盖互补行业组B；开展公司初筛、财报与产业链跟踪；提出独立投资提案。5–7家公司档案、2–3份完整投资备忘录；每周更新行业变化与重点公司。行研A核对关键事实；因子研究员验证可量化信号。参与复核他人提案。
因子研究A围绕基本面与行业数据挖掘低频因子；负责字段时点、研究代码及影子信号。2–3个有经济解释的候选因子、可复现实验与数据字典；1份影子跟踪记录。因子B复核样本外、成本与容量；同时交叉复核因子B的实验。
因子研究B围绕价格、成交与风险数据挖掘低频因子；负责样本外、成本和容量验证。2–3个候选因子的验证报告、失败实验记录；1份影子跟踪记录。因子A复核数据处理与经济逻辑；同时交叉复核因子A的实验。
AI架构师搭建数据接入、研究知识库、Agent工作流、权限日志与评测体系；处理系统故障。可追溯知识库、公告/财报与风险提示两个工作流、固定评测集及故障回退方案。行研抽检事实与引用；因子研究员复核数据和计算。架构师负责技术质量。

三种组合的取舍

3行研＋2因子：覆盖更广，但需外包AI平台建设。
2行研＋3因子：探索更快，但工程和独立验证容易拥堵。
2行研＋2因子＋1 AI架构师：适合把AI作为核心生产方式，前提是有可靠的外部运营与独立复核。

招聘未按时完成的降级路径

并行招聘AI架构师、行研和两名因子；第30天若架构师未到岗，采购受控检索/数据工具、内部保留权限；若因子验证岗缺席，只做纸面回测与影子运行。

04｜AI研究系统：先把可追溯性做成底座

所有Agent共用同一数据、权限和评测体系

授权数据公告/财报、行情、行业资料、合法获取的纪要；记录许可与使用范围。
时点数据层原文、发布日期、入库时刻、修订历史、复权与退市样本统一留存。
研究知识库按公司/产业链/主题组织；检索返回原文位置与抓取时间。
模型与工具层提示词、模型、代码、数据版本及调用成本全部登记。
评测与审批固定样本测事实、引用、计算与拒答；人工复核后写入正式结论。
审计与回退谁查了什么、改了什么、谁批准都留痕；异常时回退人工流程。
建设顺序：优先购入合规数据与文档存储，做轻量检索和工作流；不要让模型直接覆盖原始数据。将资料分为公开、内部、敏感三级，外部模型仅接收授权公开资料或脱敏内容，统一记录调用人、费用与留存期限。每份研究结论自动附“来源链接/页码、可得时点、版本号、人工复核人”；无来源的关键事实标记“待核”，不进入投委会材料。

05｜Agent矩阵：输入、产出、复核、错误监控

Q4只上线辅助决策；自主交易另行立项审批

Agent输入 → 标准产出人工复核每日/每周质量检查
公告与财报研究原始公告、历史报表 → 关键数据变化、经营解释、待核问题，逐项回链原文。行研复核数字、口径与事件重要性。抽样核对引文、单位、同比基数、修订公告；关键事实错误即撤回结论。
产业链跟踪公告、价格、招投标、调研记录 → 供需变化时间线、受益/受损映射、反方证据。行研核实来源可靠度与因果关系。记录过期信息、重复消息及无法核实传闻，不自动写入事实库。
因子假设行研观察、财务/行情字段 → 经济逻辑、变量公式、预期方向、失效条件。因子A确认逻辑，因子B检查数据可得时点。监控相似假设重复提交、未来数据使用、未经授权字段。
样本外验证冻结的候选公式与数据版本 → 滚动样本外、分组、换手、成本、容量和敏感性报告。因子B交叉复核；团队评审后记录是否进入影子运行。报告训练/验证边界、失败次数和所有淘汰实验，防止只展示最佳结果。
组合风险持仓、成交、价格、限额 → 集中度、风格/行业暴露、流动性及异常提醒。当日轮值成员初查，相关岗位交叉核验；独立方定期复核越限与处置。核对持仓源、价格异常、误报/漏报；重大告警有工单和结案时间。
投委会材料经复核的研究、因子、风险记录 → 论点/反证/估值情景/退出条件一页纸。提案人及非作者同事复核；交易人员仅看按公司授权批准的指令。检查未核事实、引用失效和审批版本与交易版本不一致。

06｜股票池与因子实验：AI产生假设，人来筛选

池子规模和频次为初期建议，随研究产能调整

主观股票池与ETF池

按两名行研产能，先建40–60只观察池、10–15只重点池，其中4–6只形成完整投资备忘录；每家公司记录入池理由、核心变量、估值情景、反证和退出条件。新增由一名行研提案、另一名行研交叉复核；每周清理失效标的。ETF先列5–10只，按跟踪标的、流动性、折溢价、费用及替代性评估。

低频因子研究流水线

经济机制 → 字段和可得时点 → 全样本含退市/停牌处理 → 基准、行业与风格中性化 → 滚动样本外 → 换手/冲击/费用 → 容量与拥挤度 → 影子运行 → 团队交叉评审并按公司授权决定是否上线。每一步记录失败与修改，禁止反复筛选后只提交最优回测。

实验关口明确的验收物常见失真及处理
数据时点字段字典、发布日期与使用滞后、复权/财报修订规则。前视数据、幸存者偏差；发现即重跑。
样本外冻结公式后滚动验证，披露每段表现、基准与行业/风格暴露。参数过拟合；失败记录不删除。
经济可行换手、交易费率、冲击成本、流动性及目标资金量容量。纸面收益无法成交；降规模或淘汰。
上线决策影子组合日志、与人工研究互补性、失效触发器和撤回责任人。相似因子重复押注；合并或限额。

08｜Q4与90天执行计划

按岗位交付和实盘记录推进；加资条件见第02节

时段五人团队研究与AI交付资金节点
10/20–11/03
定框架		现有行研确定两组行业覆盖；同步启动行研、两名因子和AI架构师招聘，明确每岗交付与交叉复核对象。优先列出A股数据源与研究字段，同时梳理美股、港股及ETF的交易日历、币种和数据差异；确定研究与Agent评测模板。确认首期以A股为主的交易范围与账户条件，形成1,000万元试运行清单。
11/04–11/19
搭底座		到岗成员按平行岗位认领行业、因子与系统模块；招聘继续并行。建立可回链的公告/财报知识库、初版观察池和ETF池；跑通因子数据时点检查，以及公告/财报研究、组合风险提示两个Agent原型。完成账户、指令、成交及日对账演练；条件具备后启动以A股为主的1,000万元实盘。
11/20–12/19
跑实盘		两名行研各形成公司档案；因子研究A提出候选，因子研究B开展样本外、成本与容量验证；AI架构师记录模型错误和人工修订。首期A股观察池扩至40–60只、重点池10–15只；形成首批投资备忘录、因子样本外/成本报告及Agent运行日志。连续记录净值、回撤、交易成本和资金流；满4周后再按第02节评估2,000万元档。
12/20–2027/01/18
做复核		核对Q4五人到岗与各岗交付；对未完成项明确接手人和完成日。累计完成4–6份完整投资备忘录；因子研究A提交2–3个候选，因子研究B完成对应验证报告；出首份AI质量和实盘归因报告。核对2,000万元档的收益、回撤、运行和容量条件；未满足则维持1,000万元。后续3,500万、5,000万按第02节逐档运行。
